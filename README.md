# 猫ボール

まるくなったネコが、どこまでも続く家の中をころがっていく 3D 前進スクロールゲーム（Three.js）。

## 遊び方
- 床の上ではネコはボール。家具にぶつかるとダメージ（ライフ3）。
- タップ／クリック／スペースでジャンプすると、ネコが身体を広げて元の姿にもどる。
- 床にいないとき（ジャンプ中・テーブルの上）は家具をぶっ壊せる！
- テーブルやカウンターの上に着地すると、その上をとことこ歩ける。
- おさかなを集めて、家具をこわして、スコアをのばそう。

| 操作 | PC | スマホ |
| --- | --- | --- |
| 左右移動 | ← → / A D、マウスドラッグ | 左右にドラッグ |
| ジャンプ | スペース / ↑ / クリック | タップ |

スコア = きょり(m) + おさかな×10 + こわした家具×20

## 起動
`index.html` をブラウザで開くだけ（Three.js は CDN から読み込み）。
ローカルサーバーで開く場合:
```
python3 -m http.server 8000
```
